# Lookout Calibration Log

Hand-scored eval runs and notes on relevance-judgment drift. The point of
this log is the same as Scout's: when Lookout starts judging "useful for
today" differently from how Mal judges it, the drift shows up here long
before it shows up in the brief.

Each entry: date, what was scored, the score, the drift note (if any),
the action taken (rubric tweak, system-prompt tweak, no change).
